# DevConnect 🚀

DevConnect is a **real-time collaborative debugging platform** that bridges the gap between **GitHub** and **Stack Overflow** by giving developers a live space to solve coding issues together.

It features **Collaboration Rooms** where multiple developers can troubleshoot code simultaneously in a **synchronized editor**, making debugging more interactive, social, and efficient.

## 🌐 Live Demo
[DevConnect Live](https://dev-connect-two-henna.vercel.app)

---

## 📌 Features

- 🔐 User Authentication (Signup / Login)
- 💻 Real-time collaborative code editor
- 👥 Collaboration Rooms for live debugging
- ⚡ Instant code synchronization using Socket.io
- 💬 Real-time chat between developers
- 🤖 AI-powered debugging/helper support
- 📱 Responsive modern UI
- 🧭 Explore and discover rooms easily
